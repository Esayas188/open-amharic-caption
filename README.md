# Open Amharic Caption

Open Amharic Caption is a Windows desktop application that generates timestamped subtitles from audio and video files using AI-powered speech recognition.

### Features
- Generate Amharic and English subtitles.
- Process supported audio and video files.
- Export subtitles in SRT format.
- Simple graphical user interface.
- Downloadable packaged Windows application.

### Download
